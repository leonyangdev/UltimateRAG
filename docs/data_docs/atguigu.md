📚 人工智能大模型课程大纲 (5.5个月)
核心技能 课程设计特色
全面培养：从 Python 基础到深度学习、大模型微调及多模态应用。实战导向：包含 8 个大型项目实战（如智图寻宝、AI 智评、RAG 项目等）。前沿技术：覆盖 LLaMA, Qwen, DeepSeek, Transformer, RAG, Agent 等最新技术栈。 课程注重理论与实践结合，通过综合案例提升实际问题解决能力。从底层算法原理到上层应用落地，为学生构建扎实的知识体系，提升在人工智能领域的综合竞争力。
